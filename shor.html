Shor's Algorithm Overview

Shor's algorithm factors a composite number using order finding. This simulation shows the classical modular arithmetic step.

  • Goal: factor a composite number N
  • Choose base: a where 1 < a < N
  • Order finding: smallest r such that a^r ≡ 1 (mod N)
  • Factor extraction: compute gcd(a^(r/2) ± 1, N)

Shor Algorithm Steps
1. Pick N and a

Choose a composite number N and a base a with 1 < a < N.

2. Compute gcd(a, N)

If gcd(a, N) > 1, then a non-trivial factor has already been found.

3. Find order r

Find the smallest r such that a^r % N == 1.

4. Extract factors

If r is even and a^(r/2) ≠ -1 mod N, compute gcd(a^(r/2) ± 1, N) for non-trivial factors.

Pseudo Implementation

 
choose composite N and base a
if gcd(a, N) > 1:
  return gcd(a, N)
find smallest r where a^r % N == 1
if r % 2 == 0 and a^(r/2) % N != N-1:
  return gcd(a^(r/2)-1, N), gcd(a^(r/2)+1, N)
else retry with another base
