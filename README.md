# Quantum Algorithm Visualizer

A simple static web project demonstrating quantum computing concepts through visual and interactive HTML pages.

## Overview

This repository contains a front-end demonstration of two foundational quantum algorithms:

- **Grover's algorithm** for unstructured search.
- **Shor's algorithm** for integer factorization.

The project is built using plain HTML and CSS, designed to run locally without a backend server.

## Project Structure

- `index.html` - Landing page and navigation hub for the project.
- `grover.html` - Interactive or explanatory page for Grover's search algorithm.
- `shor.html` - Interactive or explanatory page for Shor's factoring algorithm.
- `styles.css` - Global styling used across all pages.

## Features

- Static, browser-based UI that is easy to open locally.
- Clean layout and navigation between algorithm pages.
- Visual explanation or simulation of algorithm behavior.
- Responsive design support through shared CSS styles.

## How to Run

1. Open the project folder in your file explorer.
2. Double-click `index.html` to open it in your default web browser.
3. From the landing page, click the links to view `grover.html` and `shor.html`.

> If you prefer using a local server, you can serve the folder with any simple server such as `Live Server` in VS Code or `python -m http.server`.

## Recommended Browser

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

## Development Notes

- The project uses only static assets and does not require build tools.
- If you update CSS or HTML, refresh the browser to see changes.
- Keep relative paths intact if you move files between folders.
