Simulation Overview

This implementation follows the structure of a classical Grover search simulation in Java.

  • Search space: 16 candidate keys (4-bit key space)
  • Secret key: 9
  • Initialization: equal superposition of all keys
  • Iterations: floor(π/4 * √N)

Key Algorithm Steps
1. Initialize State

Each candidate key starts with equal amplitude 1/√N, representing an equal superposition of all possibilities.

2. Oracle

The oracle flips the phase of the secret key's amplitude, marking it for amplification without changing the others.

3. Diffusion

The diffusion operator reflects all amplitudes around their mean to amplify the marked state.

4. Repeat

Repeat oracle and diffusion for floor(π/4 * √N) iterations to maximize the probability of the secret key.

Sample Output

After the Grover iterations, the simulation reports probabilities for each key. The highest probability is the discovered key.

The Java-style simulation computes probabilities for all candidate keys and selects the most likely one.

Pseudo Implementation

 
initialize state[N] = 1 / sqrt(N)
for i in 0 .. iterations:
  oracle(state)
  diffusion(state)
print probabilities for each key
find key with maximum probability
